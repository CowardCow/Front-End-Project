[SLIDE 6: KEY FEATURES]
--------------------------------------------------------------------------------
"Starting with Slide 6: Key Features of our project, Desh Dekho.

Our website has four main feature areas:

1. Interactive Map:
   We used Leaflet map, which lets users smoothly zoom in, zoom out, and move 
   around India. You can click anywhere on the map to pick coordinates, and 
   you can switch between normal street view and satellite view.

2. Live Weather and Air Quality:
   The website shows real-time weather information such as current temperature, 
   humidity, wind speed, and pressure. It also shows the Air Quality Index, or 
   AQI, which tells you how clean or polluted the air is. Users also get a 
   5-day weather forecast, and they can easily switch between Celsius and Fahrenheit.

3. Location Management:
   Users can easily Create, View, Edit, and Delete their favorite places. 
   If you type any city name, the system automatically finds the exact place 
   using the OpenWeather API. You can also save or export your places as a 
   simple JSON file.

4. Modern and Safe User Experience:
   We have a secure login and signup system that stores user data in the 
   browser. The interface has a modern, clean glass-like look, and helpful 
   popup messages appear on screen to guide the user."


--------------------------------------------------------------------------------
[SLIDE 7: TECH STACK USED]
--------------------------------------------------------------------------------
"Moving on to Slide 7: Tech Stack Used.

Here are the main technologies we used to build Desh Dekho:

1. On the Front-End:
   - React 18: We used React to build reusable and fast UI components.
   - Vite: We used Vite as our build tool. It makes the project load and run 
     very quickly.
   - Leaflet.js: This is the library powering our interactive map.
   - HTML5, CSS3, and Lucide Icons: Used for the clean layout, glass design, 
     and simple icons.

2. On the Back-End:
   - Node.js: We created a lightweight server using Node.js and a REST API.
   - File System Module (FS): Used to read and save saved locations directly 
     into a file called locations_db.json.
   - Browser LocalStorage: Used to save user account details locally inside 
     the browser.

3. External APIs:
   - OpenWeather API: This is the core API that gives us live weather data, 
     5-day forecasts, air pollution metrics, and city search coordinates.
   - We also used NPM (Node Package Manager) to manage all our project packages."
